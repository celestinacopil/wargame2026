BELVARIAN BUSINESS REGISTER – WARGAME FILES

Files:
- index.html: searchable registry landing page
- company-belvarian-maritime.html: company record for the ship-owning company
- company-vesta-holdings.html: company record for its corporate shareholder

Deployment:
1. Upload all three HTML files into the same folder in your GitHub repository.
2. If using GitHub Pages, enable Pages for the repository/branch as usual.
3. Open index.html (or the published Pages URL) to use the registry.

No backend, database, external libraries, images, or network calls are required.
The search works locally in the browser and searches company names, registration numbers,
locations, legal forms and a small set of activity keywords.
